# CLM5 simulations over Switzerland: Input data generation and analysis
Code to reproduce results and analysis of the following manuscript: 
#### Malle J., Mazzotti G., Karger D., and Jonas T.: Regionally optimized high-resolution input datasets enhance the representation of snow cover in CLM5, Earth Syst. Dynam., 2024
Author: Johanna Malle (<mailto:johanna.malle@wsl.ch>)

All CLM5 simulation result and land surface forcing datasets used in the analysis scripts are available from the [WSL data repository EnviDat](https://doi.org/10.16904/envidat.525), as are [FSM2 snow simulation results](https://doi.org/10.16904/envidat.404). 

## Main scripts
* General analysis scripts used in this study are found under [clm5_analysis](clm5_analysis)
* Scripts used to generate figures of paper can be found under [clm5_analysis/figures](clm5_analysis/figures)
* exemplary scripts/software environment showing the CLM5 setup for point/regional-scale simulations can be found under [run_CLM5](run_CLM5)
* Scripts used to generate input (meteorological and land-use related) can be found under [input_data](input_data)
